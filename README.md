# Classroom Noise Tracker

A friendly noise meter for a preschool classroom. Open `index.html` in a browser on a laptop, tablet or classroom screen, press **Start listening**, and allow the microphone.

- A face changes from 😊 green to 😐 yellow to 🙉 red as the room gets louder.
- The class earns a ⭐ for each stretch of quiet time (60 seconds by default).
- Teacher settings: the too-loud limit, mic sensitivity, how long a star takes, an optional chime, and whether a too-loud moment restarts progress toward the next star. Settings are remembered on that device.
- Full-screen mode for a projector or smartboard.

Everything runs in the browser. No audio is recorded or sent anywhere.
